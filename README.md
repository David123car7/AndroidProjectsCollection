# Android Projects Collection 📱

A collection of Android Studio projects developed for learning, experimentation, and app prototyping.  
Each project focuses on a specific concept of Android development — from UI design to API integration and beyond.

> **Academic Context**  
> This project was developed as part of the “Mobile Devices Programming” (Programação de Dispositivos Móveis) course in the third year of the Computer Systems Engineering degree (Licenciatura em Engenharia de Sistemas Informáticos) at the Polytechnic Institute of Cávado and Ave (Instituto Politécnico do Cávado e do Ave — IPCA).

## 🚀 Projects Included

### 🧮 Calculator
A simple calculator app demonstrating:
- Basic UI layout using Jetpack Compose
- Handling arithmetic operations and input 

### 🛍️ ProductsListAPI
An app that interacts with a REST API to:
- Fetch and display a list of products
- View detailed product information
- Demonstrate the use of JSON parsing in Android
- Showcase clean architecture and composable UI elements

## 🧰 Tech Stack

- **Language:** Kotlin  
- **Framework:** Android Studio (Jetpack Compose)  

## 🧠 Purpose

This repository serves as a growing portfolio of Android applications, created to:
- Practice different Android development concepts  
- Explore modern libraries and best practices  
- Build reusable components for future projects
